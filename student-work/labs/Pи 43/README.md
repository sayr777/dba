# Лабораторные работы — Пи 43

Сюда кладите файлы лабораторных работ.

## Формат именования

```
lab_NN_фамилия.md
```

Пример: `lab_01_ivanov.md`

## Шаблоны

В папке `../../templates/` лежат шаблоны файлов-артефактов для всех лабораторных.

Скопируйте нужный шаблон, заполните своими данными, переименуйте:

```bash
cp ../../templates/lab_01_erd.mermaid lab_01_ivanov.md
```

Полный список шаблонов: [../../templates/README.md](../../templates/README.md)
