# Доклады — ПИ-42

Сюда кладите файлы докладов.

## Формат именования

```
report_NN_фамилия.md
```

Пример: `report_05_petrov.md`

## Требования

Оформляйте доклад по требованиям из
[`docs/reports.md`](../../../docs/reports.md):

- Markdown (`.md`)
- **Mermaid** + **PlantUML** диаграммы
- SQL/bash-примеры без скриншотов из IDE

## Структура README.md доклада

```markdown
# Название темы

## 1. Цель и актуальность
## 2. Архитектура (Mermaid)
## 3. Установка и развёртывание
## 4. Демонстрация (SQL с выводом)
## 5. PlantUML-диаграмма
## 6. Сравнение с альтернативами
## 7. Ограничения
## 8. Ссылки
```

## Сроки

Ссылку на репозиторий с докладом сдать **за 3 дня до выступления**.
