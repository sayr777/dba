# Студенческие работы

## Зачем нужна папка `student-work/`

Основной проект — учебный курс по администрированию БД. Файлы студентов (лабораторные, доклады, дампы, логи) не относятся к учебному материалу и не должны загромождать `master`.

Поэтому все студенческие работы хранятся в `student-work/` — это «песочница», куда студенты кладут свои артефакты в своих ветках.

## Как работает процесс

1. **Студент создаёт свою ветку** (см. инструкцию).
2. **Кладёт файлы в `student-work/<группа>/`** — это его артефакты.
3. **Коммитит и пушит** в своей ветке.
4. **Создаёт MR** на `main`.
5. **Преподаватель проверяет** и мержит — работа попадает в историю проекта.

## Правила

- Каждая группа работает в **своей ветке** (см. инструкцию).
- Файлы работ кладите **только** в папку своей группы: `student-work/labs/<группа>/` или `student-work/reports/<группа>/`.
- Не редактируйте чужие папки.
- MR должен содержать описание выполненной работы.
- После мёржа ветка может быть удалена.

## Шаблоны

В папке `templates/` лежат шаблоны файлов-артефактов для всех лабораторных работ.

- Скопируйте нужный шаблон в свою папку группы
- Замените placeholder-значения на свои данные
- Переименуйте файл по формату `lab_NN_фамилия.md`

Список всех шаблонов и их назначение — в [templates/README.md](templates/README.md).
