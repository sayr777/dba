# psql

Интерактивный командный интерфейс (CLI) PostgreSQL для выполнения SQL-запросов, скриптов автоматизации и администрирования экземпляра СУБД.

---

## 1. Назначение для системного аналитика

В отличие от графических клиентов (таких как [[tools/dbeaver]]), `psql` является эталонным инструментом при:
- работе на production-серверах через SSH без графической оболочки;
- автоматизации запуска сценариев миграций в CI/CD;
- выполнении административных процедур резервного копирования и восстановления;
- точном замере времени выполнения запросов без задержек отрисовки GUI (`\timing`).

В рамках дисциплины [[course/rpd|РПД «Администрирование баз данных»]] навык работы с `psql` подтверждает индикаторы **ПК-1-И-17**, **ПК-1-И-26** и **ПК-5-И-2**.

## 2. Параметры подключения

```bash
# Подключение к локальной базе eshop под учетной записью postgres
psql -h localhost -p 5432 -U postgres -d eshop

# Подключение с помощью connection URI
psql "postgresql://analyst_ivanova:secret@localhost:5432/eshop"
```

Основные флаги CLI:
- `-h` — хост (по умолчанию localhost или UNIX-сокет);
- `-p` — TCP-порт (по умолчанию 5432);
- `-U` — имя пользователя (роли);
- `-d` — имя базы данных;
- `-f <file.sql>` — выполнить файл со скриптом и выйти;
- `-c "<command>"` — выполнить одну команду SQL/метакоманду и выйти;
- `-v ON_ERROR_STOP=1` — немедленно прервать выполнение скрипта при первой ошибке (обязательно для безопасных миграций!).

## 3. Ключевые метакоманды psql

Метакоманды начинаются с символа обратного слэша `\` и обрабатываются самим клиентом `psql`, а не сервером PostgreSQL (в конце точки с запятой не требуется).

| Команда | Описание |
|---|---|
| `\l` или `\l+` | Список всех баз данных в кластере с размерами и кодировками |
| `\c <dbname> [user]` | Переключиться на другую базу данных (и сменить пользователя) |
| `\dn` или `\dn+` | Список схем данных (namespaces) |
| `\dt` или `\dt+` | Список таблиц в текущей схеме (с модификатором `+` показывает размер на диске) |
| `\di` или `\di+` | Список индексов с их размерами |
| `\du` или `\du+` | Список ролей и их атрибутов (`SUPERUSER`, `LOGIN`, `INHERIT`) |
| `\d <table_name>` | Детальное описание структуры таблицы (колонки, типы, constraints, индексы, RLS) |
| `\dp <table_name>` | Матрица привилегий на таблицу (GRANT access privileges) |
| `\x` | Переключение режима расширенного отображения строк (удобно для широких таблиц) |
| `\timing` | Включение отображения времени выполнения каждого запроса в миллисекундах |
| `\i <path/to/script.sql>` | Выполнение внешнего SQL-скрипта в текущей сессии |
| `\q` | Выход из терминала psql |

## 4. Рецепты и безопасные практики

### Безопасное выполнение миграций в скриптах
```bash
# Флаг ON_ERROR_STOP предотвращает частичное применение скрипта при падении
psql -v ON_ERROR_STOP=1 -h localhost -U postgres -d eshop -f V002__add_categories.sql
```

### Форматирование вывода для отчетов
```sql
-- Включение расширенного вертикального вывода
\x auto

-- Экспорт результатов запроса в CSV-файл
\copy (SELECT order_id, total_amount, created_at FROM orders WHERE status = 'delivered') TO 'orders_export.csv' WITH CSV HEADER;
```
