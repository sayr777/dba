# Code of Conduct

## Наше обязательство

Мы стремимся создать открытую и доброжелательную среду, где все участники могут эффективно сотрудничать.

## Наши стандарты

**Примеры поведения, способствующего позитивной среде:**

- Использование приветливого и инклюзивного языка
- Уважение к различным точкам зрения и опыту
- Вежливное принятие конструктивной критики
- Фокус на том, что лучше для сообщества
- Эмпатия по отношению к другим участникам

**Недопустимое поведение:**

- Использование сексистского, расисткого или иного дискриминационного языка
- Троллинг, оскорбления, личные нападки
- Публикация частной информации без разрешения
- Иное поведение, которое можно обоснованно считать неуместным

## Ответственность

Участники, нарушающие Code of Conduct, могут быть удалены из проекта без предупреждения.

## Сообщить о нарушении

Сообщайте о нарушениях на: [sayr@inbox.ru](mailto:sayr@inbox.ru)

Все жалобы будут рассмотрены конфиденциально.
