# Security Policy

## Сообщить об уязвимости

Если вы обнаружили уязвимость в проекте, пожалуйста, сообщите нам:

- **Email:** [sayr@inbox.ru](mailto:sayr@inbox.ru)
- **Тема письма:** `SECURITY: [краткое описание]`

**Не создавайте публичные issue для сообщений об уязвимостях.**

## Что сообщать

- Описание уязвимости
- Шаги для воспроизведения
- Потенциальное влияние
- Рекомендуемое решение (если есть)

## Процесс обработки

1. Подтверждение получения в течение 48 часов
2. Оценка серьёзности уязвимости
3. Исправление и публикация патча
4. Благодарность сообщнику (с его согласия)

## Поддерживаемые версии

Все ветки репозитория получают обновления безопасности по мере обнаружения уязвимостей.

## Политика раскрытия

Пожалуйста, дайте время на исправление до публикации деталей уязвимости. Мы стремимся решить критические уязвимости в течение 7 дней.
